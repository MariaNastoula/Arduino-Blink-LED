# Arduino Blink LED

## Description

This is my first arduino project.

The project blinks an extrenal LED connected to an Arduino UNO
through a resistor on a breadboard. The led turns on and off 
every second.

## Components

- Arduino UNO
- Breadboard
- Jumper Wires
- LED
- USB cable
- 200Ω resistor

![Components](images/components.jpg)

## Wirring

- Arduino digital pin 5 -> 200Ω resistor
- 200Ω resistor -> LED Anode (+)
- LED Cathode (-) -> GND
